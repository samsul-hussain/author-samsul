## 🚀 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/samsul-hussain/author-portfolio.git
cd author-portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

---

## 📦 Building for Production & GitHub Pages

```bash
# Build production bundle
npm run build
```

This compiles optimized assets into `dist/`. The project is already configured for zero-setup deployment via **GitHub Actions** (`.github/workflows/static.yml`) or via the pre-built `/docs` folder under **Settings → Pages**.
